# Iris Flower Clustering Project

## Objective
Apply K-Means Clustering on Iris Dataset and visualize clusters using PCA.

## Tools Used
- Python
- Google Colab
- Scikit-Learn
- Matplotlib

## Tasks Performed
- Loaded Iris Dataset
- Applied K-Means Clustering (k=3)
- Applied PCA
- Visualized Clusters
- Compared Predicted Clusters with Actual Labels

## Conclusion
K-Means successfully grouped Iris flowers into three clusters and PCA helped visualize them in 2D.
